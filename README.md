# Awesome Why3 and WhyML

Why3 generates and dispatches verification conditions to external provers. It is a platform and intermediate language, not a single theorem prover or a proof certificate checker.

**Status:** starter collection, initial review 2026-11-15. **Curator:** unassigned — contributions welcome. Entries are original short annotations of external sources, not endorsements or copies of their content. No tool was installed or executed for this initial list.

## First exercise (not yet execution-tested here)

Open an official WhyML example, inspect each generated obligation, and compare outcomes with two configured provers.

## Assurance and interoperability

Record the Why3 driver, each external prover/version, timeout, assumptions and any unproved obligation. Successful dispatch is not the same as an accepted proof.
